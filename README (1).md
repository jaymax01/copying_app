
# File copying App
A customized file copying app used for copying, renaming and relocating picture files per user requirements. The app helps saves time and effort sorting copying and renaming files. The app is used by a photography designing company. 



## Tech Stack

* Python 
* Streamlit
* Jupyter notebooks
* CxFreeze
